CrowPanel N95 Backup

A private, single-user application that keeps encrypted PostgreSQL backup archives copied from a personal home server to the owner's own Google Drive.

What this application does

CrowPanel N95 Backup runs on its owner's personal home server. On a scheduled basis it uses rclone to transfer encrypted PostgreSQL backup archives from that server to the owner's Google Drive account.

The application is not a public backup service. It has no user accounts, is not offered to third-party users, and is operated only by its owner.

Google Drive access

The application requests Google Drive's drive.file permission. This allows it to create and manage only the backup files it creates in Google Drive. It does not grant access to other files in the owner's Drive, and it cannot access anyone else's Drive.

OAuth credentials and tokens remain on the owner's server. They are not published on this website.

Privacy

This website is informational. It uses no cookies, analytics or tracking, and it provides no access to the application or to backup data.

Read the privacy policy for details on what the application accesses, how Google Drive and rclone are used, and how data is retained.
